下载、更新与常见问题。

第一次使用，应该下载哪个？+

下载左侧完整安装包。当前安装包为 10 月 26 日版，安装完成后再应用右侧 10 月 27 日增量包，即可获得最新修复。新电脑无需额外安装 Node.js 或 Python。

已经装了 1.3.0 或 1.3.1，如何更新？+

保存任务并退出软件，完整解压累计增量包，运行 XM-Update-1.3.1-Incremental.exe，选择包含“小马剪辑台.exe”和 resources 的原软件目录。不要在 ZIP 内直接运行。建议预留 2 GB 空间。

更新会清空配置、任务和音乐吗？+

更新器只替换程序文件，并先创建备份。你的配置、登录资料、任务历史、音乐和素材会保留。需要回退时，运行包内 Restore-Previous.cmd，选择此次更新的 delta131 备份。

AI 分析和音乐生成需要什么？+

DeepSeek、豆包使用内嵌官方网页与自己的账号；Gemini 使用你配置的连接。Suno 音乐生成需有效 API 和对应额度，需要 Suno API 可联系小马获取。本地音乐推荐需要先连接自己的音乐文件夹。

下载比较慢，或者需要核对文件？+

可在下载区选择备用镜像。镜像由第三方提供，可用性和速度随网络变化；下载后可点击“SHA-256 校验”核对文件。不确定时使用 GitHub 官方源。

需要 Suno API，可联系小马获取。
